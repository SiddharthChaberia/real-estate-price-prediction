# Bangalore Real Estate Price Prediction (Python, Flask)
A simple linear regression model, to predict the real estate prices of properties in Bangalore. Original dataset can be found in the `House_Rent_Dataset.csv` file, which is taken from Kaggle.

## Setting Up
Download this entire repo first
```bash
git clone https://github.com/SiddharthChaberia/real-estate-price-prediction.git
```

### Backend
Move to the `server` folder, open CLI here, and run the following commands
```bash
pip install -r requirements.txt
```
```bash
python3 server.py
```
This will get the backend API's running, which can be accessed in the frontend with the localserver api keys.

### Frontend
The index.html is already created, so just host it locally, the UI will be ready to predict the housing prices, fetching API's from the local server where the python server.py is running.
